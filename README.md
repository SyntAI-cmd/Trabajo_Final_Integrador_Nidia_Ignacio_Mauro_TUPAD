# Trabajo_Final_Integrador_Nidia_Ignacio_Mauro_TUPAD
Plataforma web para refugios y áreas de zoonosis: publica los animales disponibles y registra el seguimiento de cada uno (vacunas, estado y fotos) en un solo lugar, en vez de planillas sueltas y publicaciones de redes. Trabajo Final de la Tecnicatura Universitaria en Programación, UTN — Ponce, Samaniego, Roveres.
